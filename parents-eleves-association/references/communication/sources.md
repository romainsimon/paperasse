# Sources officielles

Toutes les règles invoquées par le skill `communication-parents` doivent pouvoir être
retracées vers une source officielle ou une doctrine opposable. Liste tenue à jour des URL
de référence.

## Règle de traçabilité

Pour chaque obligation citée :

1. **Texte de loi** (RGPD, Code civil, Loi 1978, Code de l'éducation).
2. **Doctrine CNIL** (guide, fiche pratique, recommandation, délibération).
3. **Vulgarisation service-public.fr** si elle existe.

Si une règle ne peut pas être sourcée, l'indiquer explicitement et inviter à vérifier sur
[cnil.fr](https://www.cnil.fr).
